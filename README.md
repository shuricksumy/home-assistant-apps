# Home Assistant Apps

Personal Home Assistant add-on repository.

## Installation

Settings → Add-ons → Add-on Store → ⋮ → Repositories, and add:

```
https://github.com/shuricksumy/home-assistant-apps
```

## Add-ons

### Music Assistant Proxy

Puts a Music Assistant server running elsewhere (Docker, another machine) into the
Home Assistant sidebar via Ingress. It does not run Music Assistant itself.

See [the add-on docs](music_assistant_proxy/DOCS.md) for configuration and notes on
authentication.
